# Mini Social Network

A simple microblogging application inspired by social media platforms like Twitter/X, built with Next.js and TypeScript.

The project aims to explore full-stack development, focusing on REST API development, database integration, data management, and user interaction.

## 🚀 Technologies

- **Next.js** – React framework for full-stack development.
- **React** – User interface development.
- **TypeScript** – Static typing.
- **PostgreSQL** – Relational database.
- **Prisma ORM** – Database modeling and queries.

## ✨ Features

- [x] Basic post creation interface
- [x] Posts feed interface
- [ ] GET posts endpoint
- [ ] POST new posts
- [ ] PostgreSQL database integration
- [ ] Prisma ORM configuration
- [ ] Edit and delete posts
- [ ] User authentication
- [ ] User profiles and interactions

## 🎯 Project Goals

This project is part of my journey toward becoming a full-stack developer. Its main goals are:

- Practice building full-stack applications with Next.js.
- Understand server-side operations and API routes.
- Learn relational database modeling with PostgreSQL.
- Work with Prisma ORM.
- Implement CRUD operations.
- Understand the communication between frontend, backend, and database.

## 🛠️ Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
